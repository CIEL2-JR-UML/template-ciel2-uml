# 🛠️ Travaux Pratiques UML — BTS CIEL 2ème Année

Bienvenue dans la section des travaux pratiques. Les TP sont conçus pour être réalisés sur poste informatique avec **Visual Studio Code**, les extensions **PlantUML** et **Mermaid**, ainsi que les compilateurs **g++ (C++20)** et **Python 3**.

## 🎯 Modalités de Rendu des Étudiants

1. Chaque étudiant ou binôme travaille sur sa propre branche ou sur son dépôt dérivé du modèle :
   ```bash
   git checkout -b tp-mon-nom
   ```
2. Complétez les fichiers demandés (schémas `.puml` et codes sources).
3. Ouvrez une Issue sur GitHub en utilisant le modèle de rendu dédié : [**Rendu de TP UML**](../.github/ISSUE_TEMPLATE/rendu-tp.md).
